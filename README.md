# 🏆 My Best Ranking

A simple and intuitive web application to create, manage, and visualize your own custom rankings and top lists.
自分好みのランキングやトップリストを簡単に作成・管理・可視化できる、シンプルで直感的なウェブアプリケーションです。

---

### ✨ Features / 主な機能

- **Customization / 自由なカスタマイズ:** Create lists from scratch with your favorite items. / お気に入りのアイテムを使って、ゼロから簡単にリストを作成できます。
- **Clean Interface / クリーンなUI:** Dynamic and easy-to-use responsive design. / 動的で使いやすい、レスポンシブ対応のデザイン。
- **Pure Web Project / シンプルな構成:** Built entirely with standard web technologies (HTML, CSS, and JavaScript). / 標準的なウェブ技術（HTML、CSS、JavaScript）のみで構築されています。
